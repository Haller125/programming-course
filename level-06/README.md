# Уровень 6. Строки

- **task-1. Счётчик.** Пользователь вводит предложение. Программа выводит количество слов, букв и гласных.
- **task-2. Палиндром.** Программа проверяет, читается ли слово одинаково в обе стороны («казак», «шалаш»).
- **task-3. Шифр Цезаря.** Программа сдвигает каждую латинскую букву на N позиций. Сдвиг вводит пользователь. Сделай и шифрование, и расшифровку.
- **bonus.** Программа делает каждое слово в предложении с заглавной буквы.

Зачёт: зашифрованное в task-3 сообщение правильно расшифровывается обратно.
