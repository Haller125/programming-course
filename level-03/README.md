# Уровень 3. Циклы

- **task-1. Таблица умножения.** Пользователь вводит число, программа выводит таблицу умножения на него от 1 до 10.
- **task-2. Сумма до нуля.** Пользователь вводит числа по одному. Ввёл 0, программа останавливается и выводит сумму и количество введённых чисел.
- **task-3. Угадай число.** Программа загадывает случайное число от 1 до 100. Пользователь угадывает, программа отвечает «больше» или «меньше». В конце выводит, за сколько попыток угадано.
- **bonus.** Программа выводит треугольник из звёздочек высотой, которую ввёл пользователь.

Зачёт: «Угадай число» доигрывается до конца без ошибок.
