# Уровень 10. Починка чужого кода

Преподаватель даёт репозиторий с программой, в которой три ошибки. Сделай форк. Работа идёт в том форке, сюда положи только ссылку на него.

- **task-1.** Для каждой ошибки создай Issue: что ожидалось, что происходит на самом деле, как воспроизвести.
- **task-2.** Исправь каждую ошибку в отдельной ветке и открой отдельный Pull Request со ссылкой на Issue.
- **bonus.** Найди четвёртую ошибку, о которой не сказано.

Зачёт: три Issue и три PR, каждый PR исправляет ровно одну ошибку. Агента использовать можно, но описание ошибки в Issue пишешь сам.
