# Уровень 4. Массивы и списки

- **task-1. Оценки группы.** Пользователь вводит 10 оценок. Программа выводит среднюю, максимальную, минимальную и количество двоек.
- **task-2. Список покупок.** Пользователь добавляет товары, пока не введёт «стоп». Потом программа выводит весь список с номерами и общее количество.
- **task-3. Поиск.** Есть массив из 10 имён, заданных в коде. Пользователь вводит имя, программа отвечает, есть ли оно и под каким номером.
- **bonus.** Отсортируй оценки из task-1 по возрастанию своим циклом, без встроенной сортировки.

Зачёт: программа не падает, если ввести 0 товаров в task-2.
