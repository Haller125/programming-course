# Программирование, 3 курс

Задачи по уровням. Язык: Python.

## Как сдавать

Один уровень сдан, когда задачи лежат в твоём репозитории и ты можешь объяснить свой код. Домашних заданий нет: всё делается на паре, каждый идёт в своём темпе с первого несданного уровня.

1. Сделай форк этого репозитория (кнопка **Fork** вверху справа). Это твой репозиторий на весь курс.
2. Для каждого уровня уже есть папка: `level-00`, `level-01` и так далее.
3. Каждая задача в отдельном файле: `task-1.py`, `task-2.py`, `bonus.py`. Условие задачи написано в начале файла.
4. В папке уровня файл `README.md`: допиши внизу, что сделано, какие были ошибки и как ты их исправил. Две-три строки достаточно.
5. Сообщение коммита: `level-03: task-1 done`.
6. Уровни 0-7 делаются без нейросетей. С уровня 8 агент разрешён и обязателен.

Уровень принимается так: преподаватель открывает твой репозиторий, задаёт один-два вопроса по коду. Объяснил, уровень засчитан. Не смог объяснить, уровень не засчитан, даже если код работает.

Обязательные задачи нужны для зачёта уровня. Задача `bonus` по желанию, она даёт дополнительную оценку.
