# Уровень 9. Расширение проекта с агентом

Возьми свой проект с уровня 8 (скопируй `level-08/expenses.py` сюда) и расширь его через OpenCode (или другого агента).

- **task-1.** Отчёт по месяцам: сколько потрачено в каждом месяце.
- **task-2.** Удаление и редактирование расхода по номеру.
- **task-3.** Файл `PROMPTS.md` в папке уровня. Для каждой задачи: что ты попросил у агента, что он сделал не так, как ты это описал и исправил. Минимум три записи.
- **bonus.** Попроси агента добавить лимит бюджета на месяц с предупреждением при превышении.

Зачёт: программа работает, и в `PROMPTS.md` есть хотя бы одна ситуация, где агент ошибся и ты это исправил. Код без `PROMPTS.md` не принимается.
