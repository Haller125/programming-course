# Уровень 8. Мини-проект без агента

**Учёт расходов.** Консольная программа с меню:

1. Добавить расход: сумма, категория, дата.
2. Показать все расходы.
3. Показать сумму по категории.
4. Сохранить в файл и загрузить из файла при запуске.
5. Выход.

Каждый пункт меню отдельной функцией. Этот уровень собирает всё, что было на уровнях 1-7, и делается без нейросетей.

Код пиши в `expenses.py`.
