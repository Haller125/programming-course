# Уровень 11. Финальный проект

Свой проект на выбор, с агентом. Варианты: Telegram-бот (расписание, напоминания, викторина), консольная игра, утилита для своей работы или работы родителей (учёт заказов, калькулятор стоимости), простой сайт на GitHub Pages.

Обязательно:

- отдельный репозиторий с понятным названием;
- `README.md`: что делает программа, как запустить, скриншот;
- `PROMPTS.md` как на уровне 9;
- минимум 10 коммитов в разные дни;
- демонстрация на паре: запуск и ответ на два вопроса по коду.

Зачёт: программа запускается на компьютере преподавателя по инструкции из README.
