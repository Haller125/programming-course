# Уровень 7. Файлы

- **task-1. Записная книжка.** Пользователь вводит заметки, программа дописывает их в файл `notes.txt`. При запуске программа сначала показывает все старые заметки.
- **task-2. Ведомость.** Создай файл `grades.csv` из 10 строк вида `Имя,оценка`. Программа читает файл и выводит средний балл и лучшего студента.
- **task-3.** Программа из task-2 сохраняет результат в новый файл `report.txt`.
- **bonus.** Если файла `grades.csv` нет, программа не падает, а выводит понятное сообщение.

Зачёт: после перезапуска программы заметки из task-1 сохранились.
