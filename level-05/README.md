# Уровень 5. Функции

- **task-1. Калькулятор.** Четыре функции: сложение, вычитание, умножение, деление. Программа спрашивает два числа и операцию, вызывает нужную функцию. Деление на ноль выдаёт сообщение, а не ошибку.
- **task-2. Проверка пароля.** Функция получает строку и возвращает, надёжный пароль или нет: не короче 8 символов, есть цифра, есть заглавная буква. Программа проверяет пароли, пока пользователь не введёт надёжный.
- **task-3.** Перепиши task-1 уровня 4 так, чтобы средняя, максимум и минимум считались в отдельных функциях.
- **bonus.** Функция, которая проверяет, простое ли число, и программа, которая выводит все простые числа до 100.

Зачёт: в task-3 основная часть программы не длиннее 10 строк, всё остальное в функциях.
